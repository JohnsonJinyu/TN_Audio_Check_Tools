## 维护建议

- 新增 docs 文档时，优先补这份索引，不要让目录继续堆平。
- 如果一篇文档已经从"专题说明"变成"总入口"，优先把原有零散说明并入，而不是继续新增并列文件。
- 开发记录类文档保留时间线，架构类文档保持当前态，不要把两类内容混写在同一篇里。
